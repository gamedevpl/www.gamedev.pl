## Copilot coding agent caveat (affects listing copy)

The Copilot coding agent supports MCP **tools only** (no resources/prompts — fine, we
expose tools only) and **does not support OAuth** for remote servers — auth is a header
fed from repo secrets. Listing copy and docs for this surface should lead with the
`Authorization` header configuration, not OAuth.
